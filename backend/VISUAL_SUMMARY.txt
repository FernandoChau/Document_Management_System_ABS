┌─────────────────────────────────────────────────────────────────────────────┐
│                       O SISTEMA EM 30 SEGUNDOS                             │
└─────────────────────────────────────────────────────────────────────────────┘

   Você entra com login/senha
            ↓
   Sistema gera um TOKEN
            ↓
   Você cria uma PASTA com nome único
            ↓
   Você faz UPLOAD de documentos
            ↓
   Sistema atribui NÚMEROS sequenciais automaticamente
            ↓
   Cada ação é registrada em AUDITORIA
            ↓
   Você pode VER, BAIXAR ou DELETAR documentos


┌─────────────────────────────────────────────────────────────────────────────┐
│                          6 ROTAS PRINCIPAIS                                 │
└─────────────────────────────────────────────────────────────────────────────┘

   POST   /entrar                      👤 Fazer login
   
   POST   /pastas                      📁 Criar pasta
   GET    /pastas                      📂 Listar pastas
   
   POST   /pastas/{id}/upload          📤 Enviar arquivo
   GET    /documentos/{id}             📄 Ver documento
   GET    /documentos/{id}/baixar      ⬇️  Baixar arquivo
   DELETE /documentos/{id}             🗑️  Deletar documento


┌─────────────────────────────────────────────────────────────────────────────┐
│                          3 RECURSOS DO SISTEMA                             │
└─────────────────────────────────────────────────────────────────────────────┘

   📁 PASTA (Folder)
      ├─ ID único (UUID)
      ├─ Nome da pasta
      ├─ Código único: "fin.contratos"
      ├─ Pode ter subpastas
      └─ Associada a departamento

   📄 DOCUMENTO (Document)
      ├─ ID único (UUID)
      ├─ Nome original do arquivo
      ├─ Código sequencial: "fin.26.001.nome"
      ├─ Tamanho e tipo MIME
      ├─ Arquivo em storage (nome aleatório)
      └─ Data de upload

   📊 AUDITORIA (AuditLog)
      ├─ Quem fez
      ├─ O que fez (VIEW, DOWNLOAD, UPLOAD, DELETE, CREATE)
      ├─ Em qual recurso
      └─ Quando (timestamp)

┌─────────────────────────────────────────────────────────────────────────────┐
│                         FLUXO DE TESTE (7 PASSOS)                          │
└─────────────────────────────────────────────────────────────────────────────┘

   [1] POST /entrar
       └─ Faz login
       └─ Recebe: token
   
   [2] GET /pastas
       └─ Lista pastas do usuário
       └─ Recebe: array de pastas
   
   [3] POST /pastas
       └─ Cria nova pasta
       └─ Recebe: folder com id + reference_code
   
   [4] POST /pastas/{id}/upload
       └─ Upload de 2 arquivos
       └─ Recebe: array com documentos criados
   
   [5] GET /documentos/{id}
       └─ Vê documento
       └─ Recebe: documento + conteúdo extraído
   
   [6] GET /documentos/{id}/baixar
       └─ Baixa arquivo
       └─ Recebe: arquivo em binary
   
   [7] DELETE /documentos/{id}
       └─ Deleta documento (soft delete)
       └─ Recebe: 204 No Content


┌─────────────────────────────────────────────────────────────────────────────┐
│                         SEGURANÇA EM 4 CAMADAS                             │
└─────────────────────────────────────────────────────────────────────────────┘

   🔐 Camada 1: AUTENTICAÇÃO
      └─ Login obrigatório → Token Bearer
   
   🔐 Camada 2: ARMAZENAMENTO
      └─ Arquivo com nome aleatório (abc123...)
      └─ Fora do web root
      └─ Não acessível via URL direta
   
   🔐 Camada 3: CONTROLE
      └─ Locks pessimistas evitam duplicação
      └─ Transações garantem integridade
   
   🔐 Camada 4: AUDITORIA
      └─ Cada ação é registrada
      └─ Quem, O quê, Quando
      └─ Imutável


┌─────────────────────────────────────────────────────────────────────────────┐
│                    EXEMPLO: GUARDAR CONTRATOS DE 2026                      │
└─────────────────────────────────────────────────────────────────────────────┘

   1️⃣  Entro no sistema
       POST /entrar
       ├─ Email: seu.email@empresa.com
       └─ Password: sua-senha

   2️⃣  Crio pasta para contratos
       POST /pastas
       ├─ name: "Contratos 2026"
       ├─ department_id: "123-456" (Financeiro)
       └─ Recebo: reference_code = "fin.contratos-2026"

   3️⃣  Envio 3 contratos
       POST /pastas/{id}/upload
       ├─ files: [contrato1.pdf, contrato2.pdf, contrato3.pdf]
       └─ Recebo:
          ├─ Doc1: "fin.contratos-2026.26.001.contrato1"
          ├─ Doc2: "fin.contratos-2026.26.002.contrato2"
          └─ Doc3: "fin.contratos-2026.26.003.contrato3"

   4️⃣  Meu gerente vê documentos
       GET /documentos/{id}
       └─ Recebe: documento com conteúdo extraído

   5️⃣  Meu gerente baixa arquivo
       GET /documentos/{id}/baixar
       └─ Arquivo transferido para computador dele

   6️⃣  Sistema registra tudo em auditoria
       ├─ Upload em 14:40
       ├─ Visualização em 15:10
       └─ Download em 15:15
